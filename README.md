# 篮球伙伴 · CourtVision

面向篮球爱好者的个人训练空间：观察动作 → 练一个问题 → 记录 → 再比较。

网站：https://andyshan11.github.io/courtvision/

## 使用

1. 调整训练档案，选择阶段、方向和可用时间。
2. 在动作实验室选择本地录像，可与自己上一次或授权示范并排、叠加、对齐、慢放，开启人体关键点辅助观察。
3. 记录一个具体问题，查看对应练习，计时并手动确认完成次数。
4. 在相同条件下比较记录，导出教练报告、JSON备份和成长卡片。
5. 设置不超过60秒的片段，可在本机实时导出带标题的无声WebM视频。

录像不上传。记录保存在当前浏览器，跨设备需要导入备份。摄像头只在主动开启时取景，退出实验室即关闭。旧比赛工作台仍在 `film.html`，保留699条已保存事件与原有本机复核记录。

## 开发

无构建步骤。Node.js 22以上：

```sh
node tools/serve.mjs
# http://127.0.0.1:4189/courtvision/
node --test test/companion.test.mjs
```

`companion/app.mjs` 负责界面流程；`core.mjs` 包含数据校验、推荐规则、统计、挑战和角度计算；`pose-worker.mjs` 在后台线程进行真实MediaPipe推理；`clip-export.mjs` 使用Canvas和MediaRecorder生成本地短片。

姿态模型和运行组件固定版本同源提供，详见 `companion/vendor/NOTICE.md` 与 LICENSE。姿态不等于篮球动作分类，更不等于正确性诊断。练习计划是规则匹配；不会伪造用户、排行榜、分数或自动识别成绩。

可选的生成式学习助手使用用户自己的本机Qwen服务，部署说明见 `companion/local-ai/README.md`。密钥留在本机环境变量，生成结果仅为待核实建议。
