# 可选本机 Qwen 学习助手

网站的动作回看、姿态模型、练习计划和记录均无需此服务。生成式训练解释使用本机 Qwen3.5-4B；不会把模型密钥写进浏览器。

已有这台开发电脑：运行 `E:/篮球创业/启动篮球AI.cmd`。原 `mvp-lab/ai-server.mjs` 现在导入本目录的 `server.mjs`，统一维护。模型和原始录像不在公开仓库。

其他电脑需要 Node.js、支持 Qwen3.5 的本机 llama.cpp 服务和自行取得的模型文件：

1. 把模型 API 绑定到 `127.0.0.1:4192`，设置自选 API 密钥，OpenAI兼容模型别名为 `Qwen3.5-4B`。
2. 在启动此进程的环境中设置 `COURTVISION_AI_KEY` 为同一密钥，执行 `node companion/local-ai/server.mjs`。不要提交密钥。
3. 访问网站「我的练习 → 连接本机 AI 学习助手」，允许浏览器访问本地网络。

服务仅监听回环地址4191。会验证Host、Origin、同源会话令牌、请求大小、JSON结构，并限制单个推理任务；iframe父页面限定为正式网站和本地开发地址。模型只生成文本草稿，不自动修改训练数据。请核实建议，特别是模型可能会对没有提供的数据作推断。

本服务与已有比赛分析兼容；`/coach` 是训练助手面板，`/coach-plan` 是训练摘要接口，`/` 和 `/analyze` 保持原比赛分析接口。更换监听端口使用 `COURTVISION_BRIDGE_PORT`（主要用于独立测试），前端仍默认为4191。
