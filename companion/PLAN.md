# 篮球伙伴 · 9月27日会议后的产品重构

依据：会议记录中面向青少年及大众的篮球学习平台、即时反馈、个性化训练、兴趣和进步、学校/培训机构/体育公园、分期开发、借用成熟技术。重做的是产品主流程，原比赛事件复核保留于 film.html。

## 本次交付与验收

- 新首页围绕「了解自己 → 看动作 → 练一个问题 → 记录 → 再比较」。真实空状态，不伪造学员、排名、成绩。
- 学员档案：昵称、阶段、方向、可用时间；本机保存并支持备份恢复。
- 动作实验室：本地视频、公开样本、双视频对比、对齐起点、同步慢放、循环区间、人体关键点和屏幕平面角度；可保存观察、关联练习。关键点检测是真实模型推理，不代表动作好坏的自动诊断。
- 浏览器姿态模型按需加载，模型和 WASM 同源托管；失败有可重试状态。视频不离开设备。
- 按目标、水平、时间和已确认问题选择练习；计时、语音提示、训练次数/成功次数/自评/教练备注，生成下次建议。规则推荐明确标明依据。
- 训练记录、同条件成功比例/样本数、历史趋势；从真实记录生成可分享的进步卡片和教练报告；JSON备份/恢复。
- 个人挑战、解锁里程碑，完成来自训练记录，不虚构多人排行榜。
- 分享入口：选定不超过60秒的片段，在本机实时导出带标题的无声WebM短视频；导出过程中可以取消。成长卡片从真实记录生成。
- 支持教练标注与报告交付；不把尚不存在的账号、付费、远程教练、公开社区做成可购买功能。
- 现有本机 Qwen 可扩展为学习助手：用户主动连接，资料在本机整理，生成的建议经用户确认后使用。
- 桌面和手机视觉验收、持久化和数据校验测试、实际视频和真实姿态模型烟测、旧工作台兼容、线上发布后验证。

## 后续阶段（需要真实用户、数据或运营验证）

1. 与教练合作验证动作标签和建议效果，做投篮/运球单项试点；星级不等于技术评分。
2. 建立跨设备账号、监护人/教练授权、机构学员管理与付费；先验证是否愿意持续使用和付钱，再设计订阅。
3. 建设授权示范动作库、动作时序识别、按年龄和水平校准的评价模型；球星相似度不能等同动作正确性。
4. 社区和真实网络赛事、奖品品牌合作、视频集锦与设备接入。需内容授权、运营和真实参赛数据。
5. 多视角3D、战术识别/成功率模型、人才数据库和硬件。单机位估计的3D关键点不宣称是真实场景重建。

本次不以完成界面替代市场验证，不声称商业化、动作诊断准确率或训练改善效果已经得到验证。
