本机分析

录像＋同场事件表 → 设置节次和时钟框 → 分析 → 复核与下载

首次使用：先启动电脑上的“启动篮球分析.cmd”，再点连接。仅支持运行本地服务的这台电脑，不是云端计算。

怎么使用？
  1. 启动本机分析服务；源码环境可在 mvp-lab 文件夹运行 npm start。
  2. 点击连接。如果浏览器提示访问本地网络，请允许。
  3. 看旧比赛：在下方“历史分析”列表选择已完成任务，不必重新导入原片。
  4. 分析新比赛：点击“新建分析”，选择录像和 JSON／JSONL 事件表（含节次、比赛时间）。
  5. 暂停到记分牌清晰的画面，框选比赛时钟，并添加各节的视频起止区间。确认资料权限后开始分析。
  6. 完成后点击事件回看，确认、排除或修正，再下载片段或索引包。

关闭页面不会取消后台任务；取消请用分析区的“取消”按钮。切回公开记录不会公开你的本地数据。若浏览器阻止嵌入，可直接打开本机工作台。
